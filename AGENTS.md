# Инструкции ИИ-агенту

## Правила стиля кода

При работе с репозиторием соблюдай следующие правила структуры проекта:

- Вся Docker-конфигурация, `.env`-файлы, конфигурация проекта `pyproject.toml` и короткий `main.py` находятся в корне репозитория. Если в одном репозитории требуется собирать несколько сервисов, Dockerfile-ы именуются по шаблону `Dockerfile.<service>`, например `Dockerfile.api` или `Dockerfile.tarantool`.
- Весь запускаемый Python-код проекта, кроме короткого корневого `main.py`, находится в `src/`.
- Кроме `src/` разрешены другие директории, например `tests/` с дополнительными `.py`-файлами для тестов, измерения метрик и подобных задач.
- В `src/common` находятся общие компоненты: enum, декораторы, кастомные exceptions, статика, например большие статические `dict`, и подобные вещи.
- В `src/models` находятся Pydantic-модели. Использование `dict` для передачи данных другим сервисам или даже функциям зачастую является плохой практикой.
- В `src/interfaces` находятся Abstract Base Classes и протоколы, задающие интерфейс реализации сервиса или класса обработки, когда это необходимо. Названия таких ABC и протоколов должны начинаться с `I`, например `IBaseRouter`.
- В `src/routers` лежит только то, что можно назвать роутером и что разделяет логику API или handler-ов.
- В `src/repositories`, и только там, находятся классы выполнения запросов и взаимодействия с данными реляционных БД, таких как SQLite и PostgreSQL. Техническая реализация пула БД находится в `src/common/database`. Репозитории работают с пулом БД; методы также могут принимать внешнее соединение, когда несколько операций репозиториев необходимо выполнить в пределах одной транзакции. Остальные аргументы и возвращаемые значения в сигнатурах методов являются Python-объектами или собственными Pydantic `BaseModel`. Использовать для них `dict` или ORM-объекты, например SQLAlchemy, нельзя.
- `application.py`, `bootstrap.py` и `container.py` находятся в отдельном слое `src/entrypoint`, чтобы не загромождать корень `src/`. Это самый верхний уровень приложения внутри `src/`, который знает обо всех остальных слоях.
- Взаимодействие с внешними сервисами находится в отдельном слое, например `src/services`, `src/infrastructure/adapters`, `src/persistence` или аналогичном. Взаимодействие с реляционной БД, например PostgreSQL, к этому слою не относится.
- `config.py`, считывающий переменные из `.env` через Pydantic Settings, находится либо в `src/common`, либо в `src/models`.Считывание env не осуществляется в других файлах src/. Остальные Pydantic-модели, не связанные с `.env`, находятся в `src/models/pydantic/`.
- Все импорты должны быть абсолютными.
